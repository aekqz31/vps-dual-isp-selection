## 双 ISP 和家宽 IP，卖的是属性不是算力

普通 VPS 的 IP 归属登记在数据中心，第三方检测工具一扫，来源显示为某个机房或云服务商，TikTok、Instagram 这类平台对账号 IP 属性敏感，机房 IP 容易被限流。双 ISP 指的是这个 IP 在归属和路由信息上同时挂在两家运营商名下，检测出来的样子更接近普通宽带用户。

WePC 美国组页面顶部写的是“全场双 ISP IP，TK 神器”，英国组写“原生 IP，可运营 TK”，两款英国家宽产品还标了“无需中转”，意思是不用再单独挂一台中转机，这台机器本身就是出口。做跨境电商账号、TikTok 带货、海外直播这类事，这类 IP 是有意义的；只是搭个静态站、跑定时脚本或者做开发测试，普通机房 IP 就够，没必要为 IP 属性多付钱。

香港组页面没有写 IP 是原生还是家宽，只写了“三网绕路，可用性高，联通优秀”。想拿香港机器做家宽 IP 用途的人，下单前最好先问清 IP 属性，别默认所有套餐都是双 ISP。

## 512MB 内存到底能跑什么

WePC 这一批机器里，有 6 个套餐的内存是 0.5GB 或 512MB。这个数字决定了它们的用途边界。

能跑的是这些：单进程的轻量客户端、监控探针、签到脚本、只放静态页的小服务，以及需要海外 IP 出口的浏览器操作。跑不动的是宝塔面板加 MySQL 再加 WordPress 这一套，面板本身通常就要占掉几百 MB，剩下那点内存撑不了数据库。开 Docker 也别指望，一个基础镜像加上容器编排的常驻进程就会把 512MB 吃满，然后开始动用 swap，机器响应变得很慢。

要建站就看最后两款 Website 机型，4 核起步、2GB 到 4GB 内存、80GB 到 120GB SSD，Classic 那款还带了 5 个站点额度、1 个 IPv6、5 个快照和 2 份备份。这组页面顶部写着“Suit for website or Email Server”，定位很清楚。需要跑数据库、多站点或者小型外贸独立站，直接上 AUD$39.90 的洛杉矶高配（4 核、6GB、40GB NVMe），512MB 那几款不用考虑。 👉 [对比 WePC 建站机型与家宽机型的配置差异](https://wepc.au/aff.php?aff=300)

## 4837 和 9929 差在哪，香港为什么写“绕路”

AS4837 是联通骨干网，带宽足、成本低，代价是回程延迟比精品网高一些，晚高峰波动更明显。AS9929 是联通精品网，定位在 4837 之上，三网方向的体验更均衡。WePC 把 AUD$12.90 的两款放在 4837 上，AUD$15.90 和 AUD$16.90 的两款放在 9929 上，AUD$39.90 的高配也走 9929 回程。这 4 澳元的差价买的就是回程线路等级，做直播这类对稳定性和延迟都敏感的场景，这笔钱值得花；只是挂个账号、偶尔登录后台，4837 也能用。

香港那两款页面自己写了“三网绕路”。绕路意味着流量不走近道直连，而是绕行其他节点，页面同时给了“联通优秀”的评价，说明联通方向的表现相对好，电信和移动方向不要期待低延迟。香港机房离得近、延迟基数低是常识，但绕路会把这点优势抵掉一部分，买之前先想清楚你用哪家宽带。

英国组写的是“电信联通可直连”，两款产品的差别在 IP 和流量：AUD$10.90 那款是普通原生 IP、1000GB 流量、超量限速 5Mbps；AUD$19.90 那款给的是英国原生家宽 IPv4，1.5TB 双向流量，三网回程优化，页面直接标了“直连即可直播”。做英国区直播或者需要英国本地宽带属性，选后者；只是要个英国 IP 做轻量用途，前者便宜 9 澳元。

## 两条硬性限制，下单前必须知道

第一条是协议限制。美国组和英国组的产品页都明确写了“严禁使用 shadowsocks 协议”，官方另行提供了搭建教程页面。这意味着拿它当代理机不符合服务条款，账号有被处理的风险。搜索“VPS购买”的人里有相当一部分目的就在这儿，这条必须先看清再决定，别付完钱才发现用不了。

第二条是流量超限的处理方式。美国四款和香港两款在超量后限速到 3Mbps 或 5Mbps，不停机、不额外收费。3Mbps 换算下来大约 375KB/s，够维持基本的网页浏览和消息收发，跑视频或者大文件下载就完全不行了。这种设计比“超量按 GB 计费”更好预算，你不会在月底收到一张意外账单，但 1.5TB 用完之后的体验落差要提前有心理准备。香港 HK_OC_42458 那款给了 8TB 流量和 500Mbps 带宽，是这一批里流量最宽裕的，AUD$59.90 的价格也是最高的。

## 几个买之前最容易问的问题

**能装 Windows 吗？** 产品组名字里带 Windows，但各套餐页面没有列出可选系统模板，具体支持哪些系统要在下单流程里看模板列表。

**流量超了会停机吗？** 不会。页面写的是超流量限速，美国款降到 3Mbps，英国和香港款降到 5Mbps。

**香港机器是双 ISP 吗？** 页面只写了“三网绕路，可用性高，联通优秀”，没有标 IP 属性，需要问客服确认。

**续费会涨价吗？** 页面只提供月付，没有首年价和续费价的区分，也就不存在首年促销、次年翻倍的情况。后续是否调价取决于商家，这一点任何商家都一样。

**512MB 能装面板吗？** 能装，但面板本身占用的内存会让剩下的空间很紧张，跑数据库基本没戏。
